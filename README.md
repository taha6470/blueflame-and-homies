# Blueflame and Homies

Vite + React (TypeScript) app built in Google AI Studio.

View your app in AI Studio: https://ai.studio/apps/drive/18mztYcs9tJai1MF4Ftg_87KJ_rCPuRmP

## Run Locally

**Prerequisites:** Node.js


1. Install dependencies:
   `npm install`
2. Create your local env file:
   - Copy `.env.local.example` → `.env.local`
   - Put your key in `GEMINI_API_KEY`
3. Run the app:
   `npm run dev`
